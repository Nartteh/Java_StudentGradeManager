
# Student Course & Grade Manager

A Java console application for managing students, courses, scores,
GPA calculation and class ranking. Built as a personal project
alongside my BIT 253 (Developmental Systems Using Java) course at KNUST.

## Planned Features
- Add, remove and search students
- Add and manage courses
- Enroll students in courses
- Record scores with validation (0-100)
- Calculate letter grades and credit-weighted GPA
- Generate student transcripts
- Rank the class by GPA
- Save and load data from a file

## Tech
- Java 17+
- JUnit (testing)

## Project Structure
- `src/model` - Student, Course, Enrollment classes
- `src/service` - business logic
- `src/storage` - file saving and loading
- `src/ui` - console menu
